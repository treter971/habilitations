# Application Habilitations
Application C# écrite sous Visual Studio 2022 Entreprise et exploitant une BDD MySQL.<br><br>

## Présentation de l'application
L’application **Habilitations** est un outil de gestion développé en C# permettant d’administrer les droits d’accès des développeurs au sein d’une application de génération de sites web.

Elle permet de gérer les utilisateurs (développeurs), de leur attribuer un profil (stagiaire, designer, développeur front-end, back-end, administrateur) et de contrôler leurs permissions sur différentes fonctionnalités.

L’application repose sur une architecture MVC avec une base de données MySQL et intègre un système d’authentification sécurisée. Elle propose une interface simple permettant d’effectuer les opérations principales : ajout, modification, suppression de développeurs ainsi que la gestion des mots de passe.

Ce projet met en œuvre des compétences en développement d’applications de bureau, en structuration logicielle et en gestion de base de données.
